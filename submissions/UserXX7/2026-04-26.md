## What I learned (or re-learned)
The staging area is a place where I prepare specific changes before committing them. It exists so I can control exactly what goes into each commit. `git add` stages changes, while `git commit` saves those staged changes to the project history. `git restore --staged` removes a file from staging without deleting it.
